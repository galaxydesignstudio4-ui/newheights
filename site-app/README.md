# New Heights School Site App (SPA)

This is the Next.js-based main site for New Heights School, powered by Supabase.

## Getting Started

1. Open a terminal in this folder:
   ```sh
   cd site-app
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) to view the site.

## Features
- SPA navigation (no page reloads)
- All content fetched from Supabase
- Modern, fast, and mobile-friendly

---

For deployment, push this folder to your GitHub repo and deploy with Vercel, Netlify, or your preferred platform.
